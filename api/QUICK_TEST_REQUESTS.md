## How to Use in Insomnia:

1. **Create a new request** for each test case above
2. **Set method to POST**
3. **Set URL to:** `http://localhost:8080/predict` (or `/predict/batch` for batch)
4. **Add header:** `Content-Type: application/json`
5. **Paste the JSON body** from above
6. **Click Send**

## Test Different Scenarios:

- **Different Breeds:** Chihuahua, Labrador, German Shepherd, Poodle, etc.
- **Different Ages:** 1 (puppy), 6 (adult), 12 (senior)
- **Different Diseases:** Bacterial Dermatosis, Fungal Infections, Staph Infection, Allergic Dermatosis
- **Different Stages:** Initial, Mild, Moderate, Severe
- **Different Environments:** Temperate, Cold, Humid, Wet, Dry, Tropical
- **Different Medications:** None, Heartworm Preventative, Beta-blockers, Insulin, Antihistamines
